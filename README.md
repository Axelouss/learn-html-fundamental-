## 🌟 Tentang Proyek

> “Dari satu tag `<html>`, kita mulai menulis masa depan digital.”

Repositori ini adalah **modul pembelajaran HTML dasar** untuk siswa **SMK Muhammadiyah 3 Tangerang Selatan**.  
Di sini kamu akan belajar struktur dasar halaman web, elemen penting HTML, dan cara menggabungkannya menjadi website sederhana tapi menarik.

---

## 🧱 Materi Pembelajaran

| 💡 Topik | 📘 Deskripsi |
|-----------|--------------|
| Struktur HTML | Mengenal `<html>`, `<head>`, `<body>` |
| Heading & Paragraf | Elemen teks dasar `<h1>` – `<h6>`, `<p>` |
| Gambar & Link | Elemen `<img>` dan `<a>` |
| Daftar | `<ul>`, `<ol>`, `<li>` |
| Tabel | `<table>`, `<tr>`, `<td>` |
| Layout & Div | Penggunaan `<div>` dan struktur halaman |
